# 运营工作台 · 使用说明

> 本说明适用于交付客户使用的正式版本。工作台为**纯本地离线**数据分析工具，所有业务数据均保存在您自己的电脑磁盘上，不上传任何服务器；仅当您主动使用「AI 助手」时，对话内容才会按您配置的服务商发送到对应的云模型接口（详见第 2 节）。

---

## 怎么打开（重要，先看这里）

> **如果您用的是客户端版**（安装后双击桌面上的「运营工作台」图标启动，或从开始菜单打开）：
> **不需要任何 .bat**，直接打开就是全部功能（含 AI 助手）。
> 本节以下的「两种打开方式」是给**网页版**用户看的，客户端版可以跳过本节，直接看第 1 节。

有两种打开方式，按您要不要使用 AI 功能来选择：

| 打开方式 | 操作 | 能用的功能 |
|---|---|---|
| **推荐：双击「启动工作台.bat」** | 会自动弹出浏览器，地址栏显示 127.0.0.1:8787 | 全部功能，含 AI 助手、AI 生成今日热点 |
| 直接双击「工作台.html」 | 直接打开网页文件 | 数据分析全部可用，但 AI 对话会失败 |

为什么要用 .bat：浏览器出于安全限制（同源策略 / CORS），不允许一个「直接打开的网页文件」去调用云端 AI 接口。「启动工作台.bat」会在您电脑上起一个**仅本机（127.0.0.1）**的小服务，网页和 AI 请求都从本机回环地址走，属于同一来源，这个限制就不存在了。该服务不监听局域网、也不会把请求转发到内网地址。

使用 .bat 时会出现一个黑色窗口，那是本地服务，**使用期间请勿关闭**，用完直接关掉即可。

> 本工具已随包附带 `node.exe`（位于本文件夹内），客户机**无需另行安装 Node.js** 即可使用 AI 功能。若提示「未找到 Node.js」，多半是 `node.exe` 被误删，请重新解压交付包。

## 1. 工作台首页（工作台.html）

工作台首页内嵌两个独立分析工具，并整合了待办、灵感、知识库与每日热点等日常运营功能。

- 左侧「运营工作台」导航栏，图标统一为简洁线条风格，分组如下：
  - 顶部：「AI 助手」橙色高亮入口（分析 + 查知识库）
  - 首页（数据概览与今日待办）
  - 复盘（完成记录与操作日志；完成的待办会自动流入这里）
  - 经营分析：店铺分析 / 单品分析 / 商品管理 / SKU明细 / 同款比价 / 利润计算 / 定价工具 / 店铺推广
  - 分析报告：付费推广分析（淘宝付费推广分析报告：ROI / 投放计划 / 关键词 / 人群 / 行动清单）/ 沟通分析报告
  - 客服中心：客服会话 / 需求洞察 / 客服分析 / 评价管理 / 问大家
  - 我的工作台：待办事项 / 灵感速记 / 个人知识库 / 产品知识库 / 每日热点 / 效率工具
  - 「设置」在窗口顶部标题栏的齿轮图标（logo 右侧、放大镜旁边），「使用说明」就在设置弹窗里。
- **鼠标滑到分组标题上，二级菜单会在右侧弹出**（不用点击展开，移开即收起）；「待办事项」「灵感速记」带数量徽标（待办显示未完成数）。
- 标题栏最左边是「收起侧栏」按钮，可把侧栏收成只显示图标的窄轨，再次点击展开。
- 点卡片或导航即在内嵌窗口打开工具；打开后顶部有「↗ 新窗口打开」和「贴顶打开」两个按钮（贴顶打开会把新窗口贴到屏幕最上方，方便并排对照）。
- 右下角有两个可拖动的**悬浮球**：**AI 助手球**（橙色，点开对话面板）与**待办事项球**（球上数字 = 今天要处理的待办数；今天有事会转成**黄色并呼吸闪烁**，有逾期则转**红色**呼吸，一眼看出「有事没做完」）。**右键**任一悬浮球会弹出快捷菜单，可「隐藏浮球」或直接进设置；被隐藏后可在「设置 → 通用 → 悬浮球」重新打开，也可以在那里分别关闭两个球。
- **所有数据**（单品分析、店铺分析，以及待办事项、灵感速记、个人知识库、产品知识库）都通过本地服务保存在您电脑的磁盘文件里（默认落在工作台文件夹所在的盘，可改存任意盘，见文末「数据存储位置」），不上传任何服务器。
- **外观主题**：支持「暗色 / 亮色 / 自动」三种主题，自动模式可按自定义时段切换；在任一页面切换后，所有工具页会即时同步。图表（含转化漏斗图等）会自动适配当前主题配色，亮色模式下采用更柔和的浅色调，不再刺眼。
- **品牌 Logo 自定义**：首页左上角黄色品牌图标支持自定义。将鼠标悬停在 Logo 上会浮现编辑按钮，点击即可修改品牌文字（中文最多 2 字、英文最多 6 字，也可留空），修改后即时生效并记忆，方便按客户/品牌个性化。

## 2. AI 助手（真实大模型）

- 已接入真实大模型（非演示）：在工作台左侧「设置」里填入服务商、Base URL、API Key 与模型名即可使用，对话由本机浏览器经本地服务中转、直连您配置的接口。
- 支持的主流服务商（OpenAI 兼容 /chat/completions）：OpenAI、DeepSeek、通义千问（阿里）、豆包（火山方舟）、智谱 GLM、Kimi（Moonshot）、Google Gemini，以及本地 Ollama 和任意自定义接口。选好服务商后 Base URL 与模型名会自动带出，也可手动改。
- 「设置」页有「测试连接」可先验证能否连通；配置只存本机浏览器，不会上传。
- 对话可勾选：
  - 「参考知识库」：让助手直接检索您的产品知识库与个人知识库来回答（尤其适合查产品卖点/规格/话术）。
  - 「基于已导入数据」：结合您导入的生意参谋数据（单品/店铺）作为上下文作答。
- AI 回复采用平铺文章式排版（无气泡），支持简易 Markdown（加粗、列表、编号、行内代码），生成中有闪烁光标提示，每条回复悬停可一键复制。
- AI 可以「动手」操作（智谱 GLM / DeepSeek / 通义 / 豆包 / Kimi 等支持函数调用的服务商）：直接说「帮我切到暗色模式」「打开店铺分析」「帮我记一条待办：明早 9 点开会」即可执行，执行结果显示在回复上方。可执行动作仅限本地白名单（切主题、跳转功能页、添加待办/灵感、开关对话选项），安全可控。
- **关于「数据是否上传」**：分析数据 100% 留在本机；但 AI 对话会按您在「设置」里选择的服务商，把对话内容（含您勾选的「参考知识库」「基于已导入数据」所带入的本地内容）发送到对应云服务商的模型接口。请仅在信任所选服务商、且遵守其服务条款的前提下使用。
- **前提：必须用「启动工作台.bat」打开**（见文档开头）。设置页底部会显示当前运行模式：
  - 绿色「本地服务已就绪 ✓」→ 可以正常用。
  - 黄色「直接打开的网页文件」→ AI 会失败，请关掉页面改用 .bat 打开。
- Base URL 一律**保持服务商官方地址**，不需要填任何代理地址，本地服务会自动中转。
- 智谱 GLM 免费方案（推荐新手）：服务商选「智谱 GLM」，模型填 `glm-4-flash`（免费），去 bigmodel.cn 注册领 Key 填入，点「测试连接」显示「连接成功 ✓」即可。
- **要粘截图识别图片**：模型必须选下拉框里带「**（支持识图）**」的视觉模型 —— 智谱 `glm-4v-flash`（免费）、通义 `qwen-vl-max`、OpenAI `gpt-4o`、本地 Ollama `llava` 等。文本模型（如 glm-4-flash）喂图片会报错，此时程序会自动改用下面的离线 OCR 重试。
- **不配任何模型也能识别截图**：程序会自动用 Windows 自带的离线 OCR（不联网、不需要 Key、不花钱），识别出的文字整段进「备注」，要点与日期由本地规则提取。质量不如视觉模型，但**完全不出本机** —— 对隐私敏感的场景优先用它。
- **待办页可以直接按 `Ctrl+V`**：会自动新建一条待办并整理内容（不用先点「新增」）；剪贴板里既没图也没文字时会提示。也可以按 `Ctrl+N` 新增。
- 若「测试连接」失败，看一眼黑色窗口里的日志：
  - 有 `API -> ...` 且 `upstream 200`：说明链路正常，问题多半在模型名写错。
  - 有 `upstream 401`：API Key 不对。
  - 完全没有新日志：说明请求没到本地服务，检查页面地址栏是不是 127.0.0.1:8787。

### 关于 API Key 的安全提示
- 您填写的 API Key 以**明文**保存在本机浏览器的 localStorage 中（仅本机可读）。在公用 / 共用电脑上使用时，建议用完清掉浏览器缓存或改用专用浏览器配置。
- 本地服务在转发时仅把 Key 发往您配置的服务商接口，不会发往其它地址；且该服务仅监听 127.0.0.1，不会暴露到局域网。

### 每日热点的「AI 生成今日热点」
- 在「我的工作台 → 每日热点」页右上角点「✦ AI 生成今日热点」，会用您「设置」里已接入的模型，按您勾选关注的行业生成一份今日热点（含 今日必看 / 多源热点 / 24H精选）。
- 生成结果会按模型返回的 `url` 直接打开真实原文（「查看原文 ↗」），无链接时降级为搜原文；生成内容存本机（key：wb_hot_gen），下次打开自动显示，无需重复生成。
- 生成后按钮变「✦ 重新生成」；点「恢复样例」可退回内置示例数据。
- 没接模型时按钮会提示先去「设置」接入。免费首选：智谱 GLM 的 glm-4-flash（在「设置」选「智谱 GLM」预设，模型名填 glm-4-flash，去智谱开放平台 bigmodel.cn 领免费 Key 即可）。
- 注意：此功能会按您的关注行业，将提示词发送给所选模型接口（属于上面「AI 功能数据外发」的范畴）。

## 3. 单品分析.html

- 用途：单个商品的流量 / 转化 / 关键词 / 词库 / 回收站等数据分析。
- 数据来源：从生意参谋等导出的 Excel（日数据、搜索词、关键词等）通过「导入」按钮导入。
- 数据通过本地服务保存到本机磁盘文件（默认工作台目录下的 data/，可改存 D: 等任意盘，见文末「数据存储位置」），不会上传任何服务器。
- **自动导入文件夹**：在工具栏根目录的 `自动导入/单品-商品数据`、`自动导入/单品-搜索词数据` 两个子文件夹中放入对应 Excel，保持「单品分析」页面打开，系统会每 5 秒自动识别并导入（详见第 7 节）。

## 4. 店铺分析.html

- 用途：整个店铺的多维度经营分析（店铺概况、店铺订单总览、店铺转化漏斗、推广、数据管理、日志、关键词、词库、行业词库、回收站）。
- **「数据管理」页导入区块顺序**（自上而下）：
  1. 店铺整体数据导入（生意参谋·店铺整体）
  2. 店铺订单数据导入（淘宝交易·宝贝销售明细报表）
  3. 店铺搜索词数据导入（生意参谋·搜索词）
  4. 行业词库数据导入（生意参谋·搜索排行·相关分析）
  5. 全店商品数据导入（淘宝·我的宝贝）
- 每个导入区均支持「点击/拖拽 Excel 导入」「📋 粘贴导入」「导入历史」「清空」，导入后右侧即时显示数据预览。
- 订单导入：表格里带「店铺名」列的会按店铺名自动分发到对应店铺，匹配不到的归入当前店铺。
- **行业对比**：在「转化分析」等页的「行业对比」区，可填写行业类目、核心搜索词及行业转化率/加购率/收藏率/点击率作为基准线；输入框已统一为整齐的表单样式，亮色/暗色下均清晰可读，填写后点「保存」即可。
- **自动导入文件夹**：在 `自动导入/` 下放入对应 Excel（店铺类 4 个子文件夹），保持「店铺分析」页面打开即可自动导入（详见第 7 节）。

## 5. 店铺推广.html（推广数据表）

- 用途：把淘宝「店铺推广数据汇总」导出的 Excel 放进来，按**六张表**查看推广明细 ——
  数据目录 / 关键词分析 / 投放计划 / 人群分析 / 商品推广 / 营销场景。
- **上传**：两种方式，选顺手的：
    · 手动：点右上角「上传表格」，或把文件拖进页面（拖到窗口任意位置都行）
    · **自动：把导出的报表直接丢进「自动导入/推广-报表数据」文件夹**
      —— 保持「店铺推广」页面打开，每 5 秒自动扫描并导入，导入完自动归档到「已导入」。
      （5 类报表可以一次全丢进去，它们会**合并**成一份分析，不是互相覆盖。）
  支持 **.xlsx / .xls / .csv**，支持**一次选多个文件**；同名文件重复上传会**覆盖**旧的（按周更新时直接再传一次即可）。
  CSV 的中文编码（UTF-8 / GBK）会自动识别，不用手动转格式。
- **看数据**：打开默认停在**行数最多的那张表**（通常是「商品推广」），点上方页签切换其它表。
  宽表默认只显示前 12 列 —— 横向滚动看后面的列（**表头和第一列固定**，滚多远都能对上行）；
  行数多时下方自动分页，每页 50 行。
- **多份数据**：每上传一个文件就是一张「数据源」卡片，可点卡片切换、点右上角 × 移除。
- 数据只存在你本机（`data/promo.json.gz`），不上传任何服务器。

## 6. 付费推广分析.html（推广报告，自动生成）

- 用途：把推广数据变成一份**能直接看的分析报告**（ROI / 投放计划 / 关键词 / 人群 / 商品 / 行动清单，共 8 章）。
- **怎么用**：先在「经营分析 → 店铺推广」上传 Excel，再打开这一页 —— 报告就出来了。
  **不需要任何操作、不调用任何模型**，全部按固定口径在本机实时计算。
  换了数据（重新上传 Excel）后，再打开这一页就是新报告。
- 报告里每个指标旁边有个「?」，点开能看到它的**计算口径**（比如 ROI = 成交金额 ÷ 广告花费）。
- 数据口径：全店指标取自「投放计划 / 商品推广 / 关键词分析 / 营销场景」这几张表
  （它们是同一份数据的不同维度切分，求和结果一致）；「人群分析」只覆盖有人群定向的那部分花费，
  单独标注占比，不与全店相加。
- 还没上传数据时，这一页会提示你去「店铺推广」上传。

## 7. 数据管理与自动导入（核心功能）

工作台提供「自动导入」能力：您只需把导出的 Excel 放进工作台根目录下 `自动导入/` 中**对应的子文件夹**，相关分析页会定时自动识别并导入，无需手动点选文件。

### 5.1 文件夹与数据类型的对应关系

`自动导入/` 目录下预置以下子文件夹（首次用 .bat 打开时由本地服务自动创建）：

| 子文件夹 | 由哪个页面自动导入 | 对应数据类型 |
|---|---|---|
| `店铺-整体数据` | 店铺分析 | 生意参谋·店铺整体数据 |
| `店铺-订单数据` | 店铺分析 | 淘宝交易·宝贝销售明细（订单） |
| `店铺-搜索词数据` | 店铺分析 | 生意参谋·搜索词数据 |
| `店铺-全店商品数据` | 店铺分析 | 淘宝·我的宝贝（全店商品） |
| `单品-商品数据` | 单品分析 | 单品商品数据 |
| `单品-搜索词数据` | 单品分析 | 单品搜索词数据 |
| `已导入` | — | 归档目录，导入成功的文件会被自动移入此处（文件名加时间戳前缀），便于追溯与留档 |

### 5.2 使用步骤

1. 用「启动工作台.bat」打开工作台。
2. 从生意参谋 / 淘宝后台导出对应的 Excel 报表。
3. 把文件**直接放进 `自动导入/` 下对应的子文件夹**（例如店铺整体数据放进 `店铺-整体数据`）。
4. 保持对应的分析页面打开（店铺类放 `店铺分析` 页、单品类放 `单品分析` 页）。系统每 5 秒轮询一次，检测到新文件即自动导入。
5. 导入成功的文件会被移入 `已导入` 归档；若导入失败，文件留在原处，修正后下次轮询会重试。
6. 也可在「数据管理」页用「点击/拖拽」或「📋 粘贴导入」手动导入，两种方式数据互通。

> 提示：自动导入依赖对应分析页面处于打开状态。若长时间未自动导入，请确认页面未关闭、文件已放入正确子文件夹，且文件名未含非法字符。

## 通用操作

- 导入：点「导入数据」选择 Excel，按弹窗提示继续（数据较大时会有加载提示，请耐心等待，别关页面）；或使用第 7 节的自动导入文件夹方式。
- 切换店铺 / 单品 / 页面：瞬时响应；图表在下一帧绘制（大表单可能稍慢，属正常）。
- 备份 / 恢复：工具内可导出备份（.json）；导入备份时单品备份只能进单品分析、店铺备份只能进店铺分析，类型不符会提示。
- 全部数据（单品/店铺分析 + 待办/灵感/知识库）保存在本机磁盘（通过本地服务），不在浏览器里。换电脑时直接把「数据备份目录」整个文件夹拷走即可；如需单独备份，也可用工具内的「导出备份」。

## 数据存储位置（重要）

单品/店铺分析、待办、灵感、知识库，所有数据都会**累积**保存。存储位置取决于您用什么方式打开：

- **客户端版**：数据由客户端内置的本地服务写成真实文件，默认落在系统的用户数据目录
  （`%LOCALAPPDATA%\com.workbench.client\data`，按模块分文件：item.json.gz / store.json.gz /
  todo.json.gz / notes.json.gz / kb.json.gz / kbp.json.gz），不占浏览器、没有 5MB 上限。
  同样可以在「设置 → 数据存储位置」里改存到其他盘，改完原数据会自动迁移。
- **用「启动工作台.bat」打开（网页版推荐）**：所有数据通过本地服务写成真实文件，落在「数据备份目录」（按模块分文件：item.json.gz / store.json.gz / todo.json.gz / notes.json.gz / kb.json.gz / kbp.json.gz）。默认是 `wb-server.js` 所在文件夹下的 `data/` 子目录（即您解压工作台所在的那个盘，例如 E:），**完全脱离浏览器、不占 C 盘、没有 5MB 上限**，几年累积都没问题。
- **直接双击 html（file://）打开**：仅作兜底，数据仍存浏览器 localStorage（约 5MB 上限，位于 C 盘浏览器目录），容量小、导入大表可能保存失败。要用自动累积保存请走 .bat。

如何改存到其他盘（例如 D:）：

**方式一（推荐，最省事）：在界面里直接设置**
1. 用「启动工作台.bat」打开工作台；
2. 左侧底部「设置」（齿轮图标）进入设置弹窗，切到「数据存储位置」；
3. 在输入框填入完整文件夹路径，例如 `D:\运营数据备份`（盘符和文件夹要真实存在），点「保存位置」；
4. 原有数据（含待办 / 灵感 / 知识库）会**自动迁移**到新位置，保存后刷新各页面即生效。无需改文件、无需重启。

**方式二（进阶）：改配置文件**
- 在 `wb-server.js` 同一个文件夹里，新建/编辑 `wb-datadir.txt`，里面只写一行绝对路径（如 `D:\运营数据备份`），**重启 .bat** 生效（黑色窗口会打印「数据存储目录: …」确认）。
- 也可以用环境变量 `WB_DATA_DIR` 指定，效果相同。

> 首次用 .bat 打开时，原本存在浏览器里的数据会**自动迁移**到磁盘文件，无需手动导出导入。

## 更新版本 / 卸载前请注意（重要）

关闭客户端**主窗口**只是把它**隐藏**（悬浮球和托盘图标继续常驻桌面，方便随时点开），
**程序并没有退出**。所以在「安装新版本」或「卸载」之前，请先**真正退出**：

- 在**右下角托盘**（或任务栏通知区域）找到工作台图标 → **右键 → 退出**
- 确认托盘图标消失后再安装 / 卸载

否则安装程序会报：

```
Error opening file for writing: ...\运营工作台\app\node.exe
```

这是因为后台还有本地服务（`node.exe`）在跑、占着这个文件。
遇到这个提示时：先点「**中止**」，按上面的方式退出客户端，再重新安装即可。
（点「重试」通常没用，因为进程还在。）

## 手机端访问（内网穿透，数据仍在你电脑）

想离开电脑时用手机记录数据、并与电脑实时同步？看同文件夹的 **`手机访问指南.md`**，按步骤：
1. 电脑打开 `http://127.0.0.1:8787/login` 设一个访问密码；
2. 安装 cloudflared，双击 **`启动隧道.bat`** 得到 https 地址；
3. 手机浏览器打开该地址、输密码即可。

数据仍只存在你电脑磁盘（实时同步、不出本机）；隧道开着期间需密码才能访问。
