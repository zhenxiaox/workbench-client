怎么打开（重要，先看这里）

有两种打开方式，按你要不要用 AI 功能来选：

  • 推荐：双击「启动工作台.bat」 —— 会自动弹出浏览器（地址栏显示 127.0.0.1:8787），全部功能可用，包括 AI 助手、AI 生成今日热点。
  • 直接双击「工作台.html」 —— 数据分析功能全部可用，但 AI 对话会失败。

为什么要用 .bat：浏览器出于安全限制（同源策略 / CORS），不允许一个「直接打开的网页文件」去调用云端 AI 接口。「启动工作台.bat」会在你电脑上起一个仅本机（127.0.0.1）的小服务，网页和 AI 请求都从本机回环地址走，属于同一来源，这个限制自然消失。该服务不会监听局域网，也不会把请求转发到内网地址。

使用 .bat 时会出现一个黑色窗口，那是本地服务，使用期间请勿关闭，用完直接关掉即可。

工作台首页内嵌两个独立工具：

  • 单品分析.html：单商品流量 / 转化 / 关键词 / 词库 / 回收站分析
  • 店铺分析.html：全店经营多维分析（店铺概况 / 订单 / 转化漏斗 / 推广 / 数据管理 / 日志 / 关键词 / 词库 / 行业词库 / 回收站）

你也可以直接双击 单品分析.html / 店铺分析.html 单独打开使用。

1. 工作台首页（工作台.html）

  • 左侧「运营工作台」导航栏，图标统一为简洁线条风格：顶部是「AI 助手」橙色高亮入口；其下常驻两项——首页（数据概览与今日待办）与复盘（完成记录与操作日志）。再往下是三个分组：经营分析（店铺分析 / 单品分析 / 商品管理 / SKU明细 / 同款比价 / 利润计算 / 定价工具）、客服中心（客服会话 / 需求洞察 / 沟通分析报告 / 客服分析 / 评价管理 / 问大家）、我的工作台（待办事项 / 灵感速记 / 个人知识库 / 产品知识库 / 每日热点 / 效率工具）。鼠标滑到分组标题上，二级菜单会在右侧弹出；待办事项与灵感速记带数量徽标。「设置」在侧边栏底部（齿轮图标），「使用说明」也在设置里。
  • 品牌栏右上角有折叠按钮，可把侧栏收成只显示图标的窄轨，再次点击展开。
  • 点卡片或导航即在内嵌窗口打开工具；打开后顶部会出现「↗ 新窗口打开」和「贴顶打开」两个按钮（贴顶打开会把新窗口贴到屏幕最上方，方便并排对照）。
  • 右下角有两个可拖动的悬浮球：AI 助手球（橙色，点开对话面板）与待办事项球（显示今天要处理的条数；今天有事会转成黄色并呼吸闪烁，有逾期则转红色呼吸）。右键任一悬浮球可快速「隐藏浮球」或直接跳到设置；被隐藏后可在「设置 → 通用 → 悬浮球」重新打开。
  • 分析数据仅存于本机（通过「启动工作台.bat」时存到本机磁盘指定文件夹，可在「设置 → 数据存储」改存任意盘），不上传；AI 功能会按设置将对话内容发往所选云模型接口。
  • 外观主题：支持「暗色 / 亮色 / 护眼 / 自动」四种主题，自动模式可按自定义时段切换；护眼模式为暖米黄低蓝光配色，长时间看数据更舒服、看产品图偏色也小。在任一页面切换后所有工具页即时同步，图表（含转化漏斗图）自动适配当前主题配色，亮色模式下采用更柔和的浅色调。
  • 品牌 Logo 自定义：首页左上角黄色品牌图标支持自定义——鼠标悬停会浮现编辑按钮，点击即可修改品牌文字（中文最多 2 字、英文最多 6 字，也可留空），修改后即时生效并记忆，方便按客户/品牌个性化。

2. AI 助手（真实大模型）

  • 前提：必须用「启动工作台.bat」打开。「设置 → AI 模型」底部会显示当前运行模式——绿色「本地服务已就绪 ✓」表示可用；黄色提示（「直接打开的网页文件」或「未在 .bat 服务下」）都表示 AI 会失败，请关闭本页、改用 .bat 打开。注意：在其它本地预览工具（如某些 IDE 内置预览）里打开也是黄色，同样不可用，必须双击 .bat。
  • Base URL 一律保持服务商官方地址，不需要填任何代理地址，本地服务会自动中转。
  • 支持的主流服务商（OpenAI 兼容 /chat/completions）：OpenAI、DeepSeek、通义千问（阿里）、豆包（火山方舟）、智谱 GLM、Kimi（Moonshot）、Google Gemini，以及本地 Ollama 和任意自定义接口。选好服务商后 Base URL 与模型名会自动带出。
  • 免费方案推荐：服务商选「智谱 GLM」，模型选 glm-4-flash（永久免费、基本不限流、最稳）；想要更强可选 glm-4.7-flash（免费但高峰易 429），去 bigmodel.cn 领 Key 填入，点「测试连接」显示「连接成功 ✓」即可。
  • 对话可勾选：「参考知识库」（让助手检索产品 / 个人知识库回答，适合查卖点 / 规格 / 话术）、「基于已导入数据」（结合生意参谋数据作答）。
  • AI 回复采用平铺文章式排版（无气泡），支持简易 Markdown（加粗、列表、编号、行内代码），生成中有闪烁光标提示，每条回复悬停可一键复制。
  • AI 可以「动手」操作（智谱 GLM / DeepSeek / 通义 / 豆包 / Kimi 等支持函数调用的服务商）：直接说「帮我切到暗色模式」「打开店铺分析」「帮我记一条待办：明早 9 点开会」即可执行，执行结果显示在回复上方。可执行动作仅限本工作台白名单内的本地操作（切主题、跳转功能页、添加待办 / 灵感、开关对话选项），不会执行其它操作。
  • 测试连接失败时，看黑色窗口日志：有 upstream 200 说明链路正常（多半模型名写错）；upstream 401 是 Key 不对；完全没新日志说明页面地址不是 127.0.0.1:8787。

3. 单品分析.html

  • 用途：单个商品的流量 / 转化 / 关键词 / 词库 / 回收站等数据分析。
  • 数据来源：从生意参谋等导出的 Excel（日数据、搜索词、关键词等）通过「导入」按钮导入。
  • 数据通过「启动工作台.bat」自动保存到本机磁盘指定文件夹（默认在工作台目录的 data/ 下，可在「设置 → 数据存储」改存 D: / E: 等任意盘，脱离 C 盘、无 5MB 上限），不上传。
  • 自动导入：把导出的 Excel 直接放进工作台根目录 自动导入/单品-商品数据 或 自动导入/单品-搜索词数据，保持「单品分析」页面打开，系统每 5 秒自动识别并导入（详见下方「数据管理 / 自动导入」）。

4. 店铺分析.html

  • 用途：整个店铺的多维度经营分析（店铺概况、订单、转化漏斗、推广、关键词、词库、回收站等）。
  • 「数据管理」页导入区块顺序（自上而下）：店铺整体数据导入 → 店铺订单数据导入 → 店铺搜索词数据导入 → 行业词库数据导入 → 全店商品数据导入。每个区支持点击/拖拽、粘贴、导入历史与清空。
  • 订单导入：表格里带「店铺名」列的会按店铺名自动分发到对应店铺，匹配不到的归入当前店铺。
  • 自动导入：把导出的 Excel 放进 自动导入/店铺-整体数据、店铺-订单数据、店铺-搜索词数据 或 店铺-全店商品数据，保持「店铺分析」页面打开，系统每 5 秒自动识别并导入。

数据管理 / 自动导入（核心功能）

工作台提供「自动导入」能力：把导出的 Excel 放进工作台根目录 自动导入/ 下对应的子文件夹，保持对应分析页面打开，系统会定时自动识别并导入，无需手动点选文件。

文件夹与数据类型对应关系：

  • 店铺-整体数据 / 店铺-订单数据 / 店铺-搜索词数据 / 店铺-全店商品数据 → 由「店铺分析」页面自动导入。
  • 单品-商品数据 / 单品-搜索词数据 → 由「单品分析」页面自动导入。
  • 已导入 → 归档目录，导入成功的文件会被自动移入此处（文件名加时间戳前缀），便于追溯与留档。

使用步骤：① 用 .bat 打开工作台；② 从生意参谋 / 淘宝后台导出对应 Excel；③ 放进 自动导入/ 下正确的子文件夹；④ 保持对应分析页面打开（每 5 秒轮询一次）；⑤ 导入成功文件移入 已导入，失败则留在原处下次重试。也可在「数据管理」页用点击/拖拽或粘贴手动导入，两种方式数据互通。

通用操作

  • 导入：点「导入数据」选择 Excel，按弹窗提示继续（数据较大时会有加载提示，请耐心等待，别关页面）。
  • 切换店铺 / 单品 / 页面：瞬时响应；图表在下一帧绘制（大表单可能稍慢，属正常）。
  • 备份 / 恢复：工具内可导出备份（.json）；导入备份时单品备份只能进单品分析、店铺备份只能进店铺分析，类型不符会提示。
  • 数据保存在本机磁盘（通过本地服务）。换电脑时把「数据备份目录」整个文件夹拷走即可；也可在工具内「导出备份」单独备份。

注意事项

  • 外观主题支持 暗色 / 亮色 / 护眼 / 自动，自动模式可按自定义时段切换，所有工具页会同步。
  • 首次打开建议用 Edge 或 Chrome；不要用 IE。
  • 若双击「工作台.html」后内嵌工具区域空白，请用 Edge 打开（个别浏览器如 Chrome 默认禁止本地文件互相嵌入）。直接双击单品分析.html / 店铺分析.html 单独使用则不受影响。
  • 有任何报错，请联系微信 zhenxiaox 及时修复解决。

同款比价 手动导入 · 离线分析

导入生意参谋「市场洞察」导出的同款商品表（CSV / 文本），自动分析价格带、销量分布与你的定价竞争力。数据不出本机。

① 导入同款数据

支持的列：标题/名称、价格/售价/到手价、销量/付款人数/支付件数、店铺、品牌、链接。列名不确定也能自动识别。

② 我的商品（用于定价对比）

填了售价后会标记你在价格带中的位置并给定价建议；成本可算出毛利率。选不同策略会改变建议锚点。
导入数据并点击「开始分析」后，这里会显示价格带分布、同款列表与定价建议。

利润计算 电商单品利润测算

输入售价与各项成本费用，实时测算单件利润、毛利率、含退换货有效利润、保本销量与预计月利润。数据不出本机。

① 基础与费用

费用项目（可增删）
费用项目可自由增删、拖拽⠿调整顺序：「%售价」按售价百分比计，「元/件」按每件固定计。运费险/退货宝每笔成交订单都收（与是否退货无关）。删除「推广费率」或「快递物流」会影响退换货损失口径（退换损失＝成本＋推广费＋双程运费）。上面「平台」选择会自动带入佣金与运费险（可手动改）。「平台活动」支持快速选让利 15%/12%/10%。

② 退货与规模（可选）

填月固定成本可算保本销量；填预期月销量可算预计月利润。退换货会按「成本+双程运费+推广费」计入损失。
填写「售价」和「商品成本」后，这里会实时显示利润测算结果。

定价工具 目标定价

给定目标毛利率 / 单件利润 / 月利润，结合成本与费用结构，推算出该定的售价。与「利润计算」对称使用。数据不出本机。

① 成本与费用

费用项目（可增删）
费用项目可自由增删、拖拽⠿调整顺序：「%售价」按售价百分比计，「元/件」按每件固定计。删除「推广费率」或「快递物流」会影响退换货损失口径（退换损失＝成本＋推广费＋双程运费）。上面「平台」选择会自动带入佣金/支付/运费险参考（可手动改）。「平台活动」支持快速选让利 15%/12%/10%。

② 定价目标

选「含退换货」会按「成本+双程运费+推广费」计入退货损失，推算出的售价更贴近真实盈利要求。
填写「商品成本」和「目标」后，这里会推算出建议售价。
